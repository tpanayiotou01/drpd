# DRPD Sneaker Catalogue

Static DRPD storefront with local product images, brand/model browsing, search and Instagram inquiries.

## Deploy on Vercel

Import this GitHub repository into Vercel. Use the Other framework preset, leave the build command empty and use `dist` as the output directory. No environment variables or installation are required. The included vercel.json sets these options.

## Edit

The deployed site lives in `dist/`: `index.html`, `styles.css`, `app.js`, `catalog.json` and local assets.
